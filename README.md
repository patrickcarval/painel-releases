# Painel — versões

Instaladores do Painel para Windows. Baixe o arquivo `Painel-Setup-x.y.z.exe` da
[versão mais recente](https://github.com/patrickcarval/painel-releases/releases/latest).

Depois de instalado, o Painel se atualiza sozinho a partir deste repositório.
O código-fonte fica em um repositório privado.
